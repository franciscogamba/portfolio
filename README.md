# Portfolio

This repository contains a WordPress plugin for building and managing the custom blocks used on my portfolio website. The blocks let me create and update portfolio content through the standard WordPress editor.

## About

I'm Francisco Gamba, a software developer. I use this project to build the tools and content blocks that bring my professional portfolio to life in WordPress.

## Approach

The custom blocks are intended to use React for their editing interfaces and compile into JavaScript files that WordPress can load. This keeps the editing experience integrated with the normal WordPress editor while allowing the portfolio blocks to have purpose-built behavior and presentation.
